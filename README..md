# Networking Labs (Cisco Packet Tracer)

This repository contains hands-on networking labs built using Cisco Packet Tracer.

## Skills Demonstrated
- IP addressing and subnetting
- Router and switch configuration
- Static routing
- DHCP and DNS setup
- Network troubleshooting

## Labs Included
- Basic Network Setup (new.pkt) - Configured initial device connectivity and verified communication using ping.
- IP Addressing Lab - Assigned IP addresses and configured devices to communicate across a network.
- Subnetting Basics - Applied subnetting to divide networks and manage IP ranges.
- Router Configuration Lab - Configured router interfaces to enable communication between devices.
- Static Routing Lab - Implemented static routes to allow communication between multiple networks.
- Enterprise Network with DHCP & DNS - Built a multi-network environment with DHCP servers and DNS for dynamic addressing and name resolution.
