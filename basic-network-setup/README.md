# Basic Network Setup

Configured a simple network topology using Cisco Packet Tracer to establish initial connectivity between devices.

## Overview
This lab focused on setting up basic connections between PCs and verifying communication across the network.

## Skills Used
- IP addressing (static)
- Device connectivity
- Network troubleshooting

## Key Tasks
- Assigned IP addresses to end devices
- Connected devices to a switch/router
- Verified connectivity using ICMP (ping)
