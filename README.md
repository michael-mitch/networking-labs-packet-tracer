# Networking Labs (Cisco Packet Tracer)

This repository contains hands-on networking labs built using Cisco Packet Tracer, covering foundational and intermediate networking concepts.

## Skills Demonstrated
- IP addressing and subnetting
- Router and switch configuration
- Static routing
- DHCP and DNS setup
- Network troubleshooting

## Lab Breakdown

### Basic Network Setup
Configured initial device connectivity and verified communication using ping.

### IP Addressing Lab
Assigned IP addresses and configured devices for proper network communication.

### Subnetting Basics
Divided networks into smaller segments using subnetting techniques.

### Router Configuration Lab
Configured router interfaces to enable communication between devices.

### Static Routing Lab
Implemented static routes across multiple routers to enable communication between networks.

### Enterprise Network with DHCP & DNS
Built a multi-network environment with routers, DHCP servers, and DNS for dynamic addressing and name resolution.

## Tools Used
- Cisco Packet Tracer

## Notes
These labs were completed as part of hands-on networking practice and demonstrate practical understanding of network configuration and troubleshooting.
