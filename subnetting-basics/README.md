# Subnetting Basics

Applied subnetting concepts to divide a network into smaller, manageable segments.

## Overview
This lab focused on understanding how subnetting improves network organization and efficiency.

## Skills Used
- Subnetting
- Network segmentation
- IP range calculation

## Key Tasks
- Divided a network into subnets
- Assigned IP ranges to each subnet
- Verified communication within and between subnets
