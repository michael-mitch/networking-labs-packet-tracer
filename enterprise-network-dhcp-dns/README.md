# Enterprise Network with DHCP & DNS

Built a multi-network environment with routing, DHCP, and DNS services.

## Overview
This lab simulated a small enterprise network with multiple LANs connected through routers, including dynamic IP assignment and hostname resolution.

## Skills Used
- Network design
- DHCP configuration
- DNS setup
- Routing and segmentation
- Network troubleshooting

## Key Tasks
- Configured multiple routers and LANs
- Set up DHCP servers for dynamic IP assignment
- Implemented DNS for hostname resolution
- Verified communication across all networks
